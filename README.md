# 🦩🚲 鹈鹕骑自行车 3D 场景

一个使用 Three.js 构建的交互式 3D 场景：一只鹈鹕在湖边环形公路上骑自行车。

## 🌟 特性展示

### 3D 渲染技术
- **程序化地形生成**：基于 FBM 噪声的自然地形，包含远山、平地和湖泊
- **物理天空系统**：使用 Three.js Sky 着色器实现真实的大气散射
- **实时阴影**：2K DirectionalLight 阴影映射 + PCF 软阴影
- **PBR 材质**：金属度/粗糙度工作流，支持清漆层
- **自定义着色器**：湖面波纹顶点动画、萤火虫粒子系统
- **后期处理**：UnrealBloomPass 泛光效果

### 场景元素
- **环形公路**：40m 半径的骑行道，带程序化虚线标记
- **树木系统**：420 棵树使用 InstancedMesh 高效渲染，混合阔叶树和针叶树
- **路灯系统**：16 盏路灯，夜晚自动点亮并投射 PointLight
- **飞鸟群**：9 只海鸥在湖面上空盘旋，带翅膀拍打动画
- **云层**：18 朵程序化云彩缓慢旋转
- **萤火虫 + 星空**：夜晚出现的 400 只萤火虫和 2500 颗星星

### 角色动画
- **程序化自行车**：完整的车架、车轮辐条、曲柄、链条、车篮
- **鹈鹕建模**：身体、头部、嘴、喉囊、翅膀、眼睛
- **双骨 IK 动画**：鹈鹕双腿通过反向运动学实时跟踪踏板位置
- **身体摆动**：骑行时的身体晃动和头部转动
- **车轮旋转**：基于物理速度的精确旋转
- **踏频计算**：实时显示 RPM（每分钟转数）

### 交互功能
- **速度控制**：滑块调节 + ↑↓ 键盘控制（0-14 km/h）
- **镜头切换**（C 键）：
  - 🎥 跟随模式：摄像机跟随自行车后方
  - 🎥 侧面模式：固定角度观察全场
  - 🎥 自由模式：OrbitControls 自由旋转缩放
- **昼夜切换**（N 键）：平滑过渡太阳高度、光照、雾色、路灯
- **车铃音效**（空格）：Web Audio API 合成双音铃声
- **背景音乐**（M 键）：简单的三角波音乐循环
- **截图功能**（P 键）：保存当前渲染画面为 PNG
- **点击交互**：点击鹈鹕触发音效

### UI 设计
- **Glassmorphism 风格**：毛玻璃面板 + 模糊背景
- **实时 HUD**：速度、里程、圈数、踏频、FPS
- **响应式布局**：适配桌面和移动设备
- **流式加载动画**：车轮旋转加载器

## 🛠️ 技术栈

- **Three.js** v0.169.0 - 3D 渲染引擎
- **ES Modules** - 原生模块化
- **Web Audio API** - 实时音频合成
- **CSS 自定义属性** - 主题系统
- **Canvas API** - 截图功能

## 📊 性能指标

- **顶点数**：约 50 万（地形 + 树木 + 水面）
- **DrawCalls**：约 15-20（InstancedMesh 优化）
- **帧率**：60 FPS @ 1080p（现代 GPU）
- **内存占用**：约 80-120 MB

## 🎨 设计理念

遵循 glassmorphism 设计系统：
- 深色主题从 `#05070C` 到 `#1E2636` 的五级表面
- 金琥珀色强调色 `#ffb347`
- 流式尺寸使用 `clamp()` 响应式缩放
- 所有圆角使用 token 系统统一管理
